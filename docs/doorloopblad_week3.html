Werkcollege 4 — de stapeling

  1. Functies met een standaardwaarde. Een parameter die je niet hoeft mee te geven. def f(x, drempel=30)
  2. Dictionary als opzoektabel. Sleutel → waarde, met een terugvaloptie. drempels.get(ronde, 30)
  3. Filteren en groeperen. Van alle regels naar alleen wat je nodig hebt, dan per groep één getal. df[df[...] == ...] · groupby
  4. De spelregels. Vier straten, dus je bot beslist vier keer per hand.
  5. Handsterkte. Welke vijf van de zeven kaarten tellen.
  6. Winkans. Hoe vaak win je — en tegen hoeveel mensen is dat gerekend? schat_winkans(hand, tegenstanders=5)
  7. Pot odds. Wat kost meedoen, uitgedrukt in een percentage. bereken_pot_odds(pot, inzet)
  8. Die twee naast elkaar is een beslisregel. Dat is de hele week.

Werkcollege 5 — van bot naar data

  1. Live testen. Studentnummer invullen, de API draait zijn bot op jouw situaties. Je ziet gedrag, geen code.
  2. De uitslag lezen. v2 naast v1, zelf de kolommen bouwen. pivot · verschilkolom
  3. De spelregels terugvinden in je eigen log. Filter één hand en je ziet de hele tafel. winst telt op tot nul
  4. Peer review. Drie criteria, verplichte toelichting.
  5. Aftrap Case 2. Onderwerp vast vóór donderdag 18:00.
  6. Twee tabellen samenvoegen op een sleutel die niet vanzelf past. merge · rijen tellen vóór en ná
  7. Van notebook naar script. Zelfde idee als de widget van vanochtend: een knop die een grafiek stuurt. ipywidgets → Streamlit
  8. Wat pas je aan? Eén ding, met de verwachting erbij.

Het toernooi als dataset — begin hier

df = pd.DataFrame(resultaat["hand_log"]).sort_values( ["bot_naam", "simulatie", "tafel", "hand_nummer"]) df["winst"] = df.groupby(["bot_naam", "simulatie", "tafel"])["stack"].diff().fillna(df["stack"] - 1000)

Het log bewaart de stack ná elke hand, dus winst is het verschil met de hand ervoor — binnen dezelfde zitting, want simulaties zijn parallelle werelden. Controle: alle winst samen is precies 0. Is dat niet zo, dan klopt je groepering niet.

Eén ding dat per toernooi omdraait: hier is de ruis binnen een bot (250) kleiner dan het verschil tussen bots (1190), dus de rangorde ligt redelijk vast. Dat komt doordat bijna iedereen hetzelfde doet — bij een gevarieerder veld kan dat omslaan.
