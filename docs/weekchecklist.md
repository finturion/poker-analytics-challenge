# Weekchecklist

Je eigen punten, naast wat `scripts/weekcheck.py` automatisch nakijkt. Alles wat
hier nog als `- [ ]` staat komt in de briefing terug; zet er een `x` in als het
klaar is. Punten onder "Elke week" komen elke week terug.

Zet hier alleen dingen in die een script niet kan zien. Bestaat een bestand wel
of niet, klopt een tijdstabel, draait de API — dat kijkt het script zelf na.

## Elke week

- [ ] Slides van deze week doorgelopen op het scherm waarop je ze geeft
- [ ] Zelf de eerste cel van elk notebook gedraaid in een verse map
